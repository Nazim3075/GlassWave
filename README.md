# GlassWave Standalone Music PWA

GitHub Pages (`nazim3075.github.io`) এ আপলোড করার জন্য সবগুলো ফাইল এই ZIP-এ একসাথে দেওয়া হয়েছে:

1. `index.html` — স্বতন্ত্র PWA অ্যাপ, মিনি প্লেয়ার ও ফুল-স্ক্রিন এক্সপ্যান্ডেড প্লেয়ার
2. `app.js` — স্পোটিফাই/ইউটিউব মিউজিকের মতো একের পর এক গান চালানোর অটো-রেডিও কিউ, শাফল/রিপিট, এবং মাল্টি-সোর্স ফলব্যাক (Saavn, JioSaavn Mirror, Monochrome, iTunes)
3. `manifest.json` — ক্রোমের অ্যাড্রেস বার ছাড়া পূর্ণাঙ্গ অ্যাপ (`display: "standalone"`) কনফিগারেশন
4. `sw.js` — Service Worker
5. `icon-192.png` ও `icon-512.png` — অ্যাপ আইকন
