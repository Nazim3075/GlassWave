# GlassWave Standalone Music PWA (v4.6)

GitHub Pages এ আপলোড করার জন্য সবগুলো ফাইল এই ZIP-এ দেওয়া হয়েছে:

1. `index.html` — মূল অ্যাপ ইন্টারফেস ও হোম প্লেলিস্ট কার্ড লেআউট
2. `app.js` — ইউটিউব মিউজিক হোম প্লেলিস্ট ও গান লিস্ট + `tracks.monochrome.st` থেকে Lossless FLAC প্লেব্যাক, দ্রুত সরাসরি সার্চ, এবং Shuffle ও Repeat (Off / All / One)
3. `manifest.json` — PWA কনফিগারেশন
4. `sw.js` — Service Worker (`glasswave-standalone-v4.6`)
5. `README.md` — নির্দেশিকা
