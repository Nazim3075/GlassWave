# GlassWave Standalone Music PWA

GitHub Pages এ আপলোড করার জন্য সবগুলো ফাইল এই ZIP-এ একসাথে দেওয়া হয়েছে:

1. `index.html` — স্বতন্ত্র PWA অ্যাপ, মিনি প্লেয়ার ও ফুল-স্ক্রিন এক্সপ্যান্ডেড প্লেয়ার
2. `app.js` — শাফল/রিপিট (Off / All / One), অটো-রেডিও কিউ, লিরিক্স ও মাল্টি-সোর্স ফলব্যাক
3. `manifest.json` — PWA কনফিগারেশন (`start_url: "./index.html"`)
4. `sw.js` — Service Worker (`glasswave-standalone-v4.5`)
5. `README.md` — নির্দেশিকা
